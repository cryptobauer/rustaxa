## Complete module units

`admission.rs` has no reader callback. `sha` and `hash` return SHA-256 text and Keccak-256 bytes. `canonical` accepts only lowercase even-length hex with optional exact width; `address` requires 20 bytes. `outside_db` rejects either database tree. `evidence` enforces exact canonical source, regular metadata, size/cap and hash; `read_capped` detects growth with a cap-plus-one read. `pair` and `identity` enforce accepted H/P/genesis/root and P/FE identity. `raw_index` validates metadata, canonical row order, uniqueness, byte totals and the recomputed digest, then returns path to original row index/value. `coverage` selects exactly one P and FE record with authenticated header/root and complete inventory/partial inverse status. `catalog_digest` and `plan_digest` preserve the accepted Stage A versioned fixed-width and length-framed digest definitions. Errors abort admission before child work. This module duplicates only narrow pure helpers so Stage A source and behavior need no refactor.

`codec.rs` contains pure versions of the retained inverse codecs. `UndelegationRow` holds arbitrary-width unsigned amount and u64 block. `decode_undelegation_v1` accepts canonical RLP `[amount,block]`; `decode_undelegation_v2` accepts `[[amount,block],id]` and returns embedded u64 ID. `decode_undelegation_row`, `exact_rlp`, `decode_uint_item`, `require_data` and `append_uint` enforce exact list shape, complete consumption, minimal unsigned integers and byte-for-byte re-encoding. Amount zero is empty RLP data; no invented 256-bit limit applies. `uint_hex` returns minimal amount bytes, including empty zero. `decode_le_u32` and `decode_le_u64` require exactly four/eight bytes. Malformed shape, nonminimal encoding, trailing bytes or numeric overflow returns an error.

The binary's `pre`, `prefix`, `item`, `reverse` and `scalar_pre` form exact literal preimages. Logical key is Keccak(preimage), and trie path is Keccak(logical key). Effective item and reverse discriminators are both 02 under the retained Go append-capacity alias. Positions are one-based LE-u32 and observed IDs are LE-u64. V1 records use `03 00 || validator || delegator`; V2 records use `03 00 || delegator || validator || id_LE8`. Allocation cursor uses `03 04 || delegator` without a count suffix. Luna's source parity map records declared versus effective discriminators.

`stage_seeds` checks accepted Stage A status/identity/counters/source bindings, all 589 raw link references, sorted 290 seeds, retained occurrence references, catalog digest and exact 810 residual subset/digest. Its authority comes from the fixed accepted Stage A hash. `Scalar` stores optional V1/group counts and cursor plus parent tuple indexes. `scalars` validates all 870 predeclared tuple keys/memberships/raw references, decodes only present values, and checks the fixed scalar summary and aggregate limits before child expansion. Missing values remain null. Present zero is a validated count, separate from a missing path.

`Catalog` keeps raw data, examined records, distinct validated paths, actual lookups and child-byte totals. `new` initializes an empty catalog. `lookup` derives one justified key and preserves P/FE, roles, preimage, logical key, trie path, parent/position and exact raw reference. It enforces 1017 lookups, 4096 bytes per child and 602112 child bytes. A miss records only `unresolved_not_in_live_inventory`. `validate` keeps decoded successful rows and counts their path once; a codec/invariant failure becomes `invalid_live`. `skip` records a dependent child group with null key/value when a parent cannot justify key derivation; it performs no lookup.

`fixed_address` requires an exact address20. `children` follows count-bounded forward item order, checks validator uniqueness and reverse positions before records/group counts, and keeps valid independent branches. It gathers every available V2 group count and checks per-group/per-seed/aggregate ID limits before any ID item. IDs must be positive, unique per delegator across groups, match their reverse positions and embedded object ID, and not exceed a present cursor. A missing cursor leaves that invariant and map incomplete. A cursor above the current IDs is valid and never drives enumeration. Missing/invalid parents prevent dependent derivation. Map and group records distinguish incomplete, invalid and successful branches. Scalar records precede children; within the outer stage seeds are sorted and V1 precedes V2, with ascending stored positions. The nested ID stage follows collected group order. Stored member order is never replaced by address or numeric ID sorting.

`catalog_digest_rows` uses ASCII `offline-undelegation-catalog-v1`, row count u32be, and each deterministic JSON row framed by byte length u64be. Object keys use serde_json's ordered map representation. Row order, provenance, decoded values and errors all affect the digest; output self-hash and timestamps are excluded. `audit` combines the admitted sources, emits all records/maps/entries, distinct family-local paths/bytes, limits and false qualification flags. `main` handles the strict CLI, pins all sources, runs the audit, serializes within the cap and exclusively writes the report. Generic identity, byte or count-cap failures return an error and publish no report; a missing/invalid child leaves explicit partial coverage.
