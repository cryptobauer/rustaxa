# S5 Cacti P-256 compatibility

Status: bounded direct-kernel implementation and dual-pin oracle. This slice adds
no production registry, historical fork selection, frame route, protocol change,
state access or publication path.

## Implemented contract

`rustaxa-evm/src/p256.rs` owns one immutable stateless invocation at exact address
`0x0000000000000000000000000000000000000100`. Preparation binds the complete
call context and quotes 6,900 native action gas without reading state or running
cryptography. Invocation checks funding first and then calls only the P-256
verification function in the repository's pinned REVM revision.

Taraxa requires exactly 160 input bytes in five 32-byte fields: message hash,
signature `r`, signature `s`, public-key `x`, and public-key `y`. A valid signature
returns the 32-byte word one. Wrong input length, invalid scalar, invalid signature
and invalid public key all complete successfully with empty output. The verifier
accepts the mathematically equivalent high-S signature retained by the Go reference.
The helper emits no account, raw-storage or log effects. Unexpected backend or gas
behavior aborts as an infrastructure failure rather than becoming a contract result.

The surrounding application still owns Cacti activation and full native-address
classification. The frame driver still owns CALL-family context, value transfer,
gas forwarding/return and rollback. Integration must add the helper to the reviewed
stateless route only when Cacti is active; it must not activate a generic Ethereum
precompile table.

## Reference evidence

`p256_reference.go` obtains address `0x0100` from the actual Cacti registry and
calls its `RequiredGas` and `Run` methods. The Python harness archives and executes
both pinned Go revisions:

- public `6c7e5338b22d5e596cc2365a88d1f94840e1ee1b`;
- local `bb0ab67c8cda1220aed74ecb01d2c4ca7c9bb418`.

Their 18-row JSON artifacts are byte-identical with SHA-256
`3ca09018b2cc09e304d549d8a388e2555bd118f1f4708bf938091562a1a1cded`.
The exporter SHA-256 is
`40f235654cb234e9869110224a3352c3c3dad91bd270338700a03231aac2b028`.
The corpus covers empty and wrong-length inputs around 160 bytes, a valid signature,
high-S acceptance, a changed message, zero and curve-order `r`/`s`, zero coordinates,
and coordinates equal to the field prime.

The Rust test compares every row at 6,899, 6,900 and 6,901 supplied gas for CALL,
CALLCODE, DELEGATECALL and STATICCALL contexts while retaining a value wider than
256 bits. It validates the quote/result binding, checks that underfunding precedes
verification, and rejects address lookalikes.
