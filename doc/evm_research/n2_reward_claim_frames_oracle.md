# Positive reward claim frame reference

This oracle measures commission and delegator claims in CALL, STATICCALL and parent REVERT frames. It uses actual canonical reward-only P1: all 92 physical rows, both existing accounts, native period 2 over committed reader 1. The wrapper replaces code only on the existing native caller in a disposable Go BlockState. The other existing account sends the outer transaction with nonce 0, gas 200000, zero value and gas price. The underlying P1 database stays unchanged after each case and repeat. This is a synthetic code experiment, not committed code or root parity.

Commission claims use owner O, selector d0eebfe2 and validator31; delegator claims use caller D and ef5cfb8c with the same validator. Native gas is 20000 or 40000. Transaction gas is 42218/62218 for CALL and parent REVERT, and 42216/62216 for STATICCALL. Each native call succeeds with empty output and one event. The wrapper returns the 32-byte success word 1. Commission pays 8, native balance 4792 and owner 1008; delegator pays 396, native 4404 and caller 3396. STATICCALL retains these effects on this pinned Taraxa native path. Parent REVERT returns `execution reverted`, restores balances and outer logs, and retains native raw writes. The outer sender nonce still advances to 1.

The first measured dual-pin capture is saved before exact assertions. The harness pins the full measured gas, account, payout, raw-write, read and log vectors. Commission has one ordered raw write; delegator has six, with the repeated node2 count collapsed in final raw state. The fixed 12-key watch scope comes from the union of actual setup reads, Run reads and writes in that first measurement. Watched bytes are independently read after execution from the canonical reader and live BlockState in observed and hook-free controls. Only call/write/balance hook fields are removed for control comparison; raw before/after fields remain. Unwatched native reads or writes fail explicitly. No values are fabricated from expected outcomes.

Both exact Go pins, fresh repeats and controls match. Source guards cover the existing account hook target; the manifest binds producer, harness, support, seed, pins, Go version and fixture hashes. Required checks and independent Sol-medium acceptance are recorded in `/home/fry/artifacts/evm-round-01a11b9c-47e5-7f92-a0f8-c4b9d7725b34-r1-20261008/claim-frames-closeout.json` when accepted. This oracle does not accept Rust by itself, historical signed simulation, mixed publication order, general nested claims, real windows, recovery, integrated N4–N6 or production cutover.
