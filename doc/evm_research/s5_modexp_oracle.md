# Bounded MODEXP oracle

`modexp_reference.go` invokes only the pinned Go Californicum address-5
precompile's `RequiredGas` and `Run` methods. It records no EVM admission,
frame, storage, receipt, or routing behavior.

The corpus covers empty/short headers, ordinary arithmetic, zero modulus and
exponent, truncation, ignored trailing bytes, output padding, lengths through
1025, exponent-head boundaries, and wide 256-bit headers whose low 64-bit
operand lengths remain bounded. Both archived Go references must agree; normal
driver mode compares the regenerated bytes and manifest to checked-in fixtures.

These vectors are input/output and quote evidence only. They do not select a
Rust implementation or imply that an Ethereum fork gas table is Taraxa parity.

## Prepared Rust adapter

`rustaxa-evm/src/modexp.rs` owns a complete immutable invocation and returns a
single-consumption quote for exact address 5. It implements the pinned gas
formula with full-width lengths and exponent-head arithmetic, saturating only
the final gas to `u64::MAX`. Invocation checks funding before allocating operand
buffers, then follows Go's low-64-bit execution lengths, right-padding, wrapped
modulus offset, zero-modulus output and zero-base/zero-modulus early return.
Only modular arithmetic is delegated to the already pinned REVM crypto primitive;
no Ethereum registry, fork gas wrapper or new dependency is selected.

The helper returns no state changes or logs and leaves registry selection,
sequence validation and frame settlement to its caller. Host allocation and
primitive errors abort as infrastructure failures. The corpus bounds every
executed operand to 1,025 bytes; it does not exercise resource exhaustion or
justify running arbitrary declared lengths with maximum supplied gas.

Two targeted tests compare all 25 corrected rows at below/exact/above quote
boundaries where representable, for all four CALL-family contexts. The corpus
includes zero and maximum quotes and full-width lengths with bounded low bits.
An additional assertion proves that unfunded maximum-length headers return
without operand allocation. Both Go pins reproduce the fixture bytes under
Python's optimized mode, where assertion statements would be disabled.

```sh
python3 -O experiments/evm_feasibility/modexp_reference.py
cargo test --manifest-path rust/Cargo.toml -p rustaxa-evm --test modexp_reference
cargo clippy --manifest-path rust/Cargo.toml -p rustaxa-evm --lib --test modexp_reference --no-deps -- -D warnings
make rewrite-validate-fast
```
